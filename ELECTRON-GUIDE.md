# Zascord Desktop — подробная инструкция по Electron (Этап 25, пункт 11)

Обёртка НЕ заливается на хостинг. Это отдельный мини-проект на вашем компьютере,
который открывает ваш сайт в нативном окне и пакуется в установщики.

---

## 1. Подготовка компьютера (один раз)

1. Установите **Node.js LTS**: https://nodejs.org (кнопка LTS, далее «далее-далее»).
   Вместе с ним ставится npm.
2. Проверьте в терминале (Windows: `Win+R` → `cmd` → Enter; macOS/Linux: Terminal):
   ```bash
   node -v     # должно вывести v18+ или v20+
   npm -v      # 9+ или 10+
   ```
   Если команды не найдены — перезапустите терминал после установки Node.

## 2. Создание проекта обёртки

3. Создайте папку вне проекта хостинга, например `C:\zascord-desktop\`
   (на macOS/Linux: `~/zascord-desktop`).
4. Скопируйте в неё **содержимое** моей папки `electron/` из выдачи:
   - `package.json`
   - `main.js`
   - `README.md` (справка, не обязателен)
   Итого в папке: `zascord-desktop/package.json`, `zascord-desktop/main.js`.
5. Откройте терминал **в этой папке**:
   - Windows:shift+ПКМ в папке → «Откнуть окно PowerShell здесь» либо `cd C:\zascord-desktop`
   - macOS/Linux: `cd ~/zascord-desktop`
6. Установите зависимости (скачается Electron ~100 МБ, один раз):
   ```bash
   npm install
   ```
   Возможные проблемы:
   - `npm ERR network` / прокси → проверьте интернет/прокси-настройки npm;
   - медленно из-за реестра → можно `npm install --registry=https://registry.npmjs.org`.

## 3. Запуск (режим разработки)

7. ```bash
   npm start
   ```
   Откроется чёрное окно 1280×800 с вашим сайтом внутри (сейчас `https://zak-messenger.web.app`).
   - F12 внутри окна — devtools (как в браузере);
   - все данные/кэш живут в профиле Electron отдельно от браузера;
   - обновления сайта прилетают сами при каждом запуске (обёртка грузит живой хостинг) —
     пересобирать обёртку после ваших деплоев **не нужно**.

8. Смена домена (когда привяжете zascord.app): откройте `main.js`,
   замените `const APP_URL = "https://zak-messenger.web.app";` → ваш домен, сохраните,
   перезапустите `npm start`.

## 4. Сборка установщиков

9. ```bash
   npm run dist
   ```
   Первый запуск докачает утилиты electron-builder. Результаты в папке `dist/`:
   - Windows: `dist/Zascord Setup x.x.x.exe` (NSIS-установщик);
   - Linux: `dist/Zascord-x.x.x.AppImage`;
   - macOS: `dist/Zascord-x.x.x.dmg` (соберётся только на macOS).

10. Установите и запустите как обычную программу. Ярлык/меню создаются установщиком.

### Иконка приложения (по желанию, но рекомендую)
11. Создайте подпапку `build/` рядом с `package.json` и положите:
    - Windows: `build/icon.ico` (256×256, формат .ico);
    - Linux: `build/icon.png` (512×512);
    - macOS: `build/icon.icns`.
    Получить из вашего `zascord.png`: любой онлайн-конвертер
    («png to ico», «png to icns») или ImageMagick:
    ```bash
    magick convert zascord.png -resize 256x256 icon.ico
    ```
    electron-builder подхватит их автоматически при следующем `npm run dist`.
    Без иконок сборка тоже работает (будет дефолтная иконка Electron).

## 5. Частые вопросы

- **SmartScreen/антивирус ругается на установщик** — это из-за отсутствия цифровой
  подписи. Лечится покупкой кода-подписи (необязательно) или кнопкой «Подробнее → Выполнить».
- **Нужен ли интернет приложению?** Да: обёртка грузит живой сайт. Офлайн переживается
  за счёт PWA-кэша оболочки + персистентного кэша Firestore (история откроется,
  новые данные подтянутся при появлении сети).
- **Обновлять обёрку при деплоях сайта?** Нет. Пересборка нужна только если меняли
  `main.js`, иконку или версию в `package.json`.
- **Хочу раздавать установщик другим** — залейте `dist/*.exe` куда удобно (сайт, диск);
  каждый пользователь получит то же окно с вашим сайтом.
- **Несколько окон / трей** — могу добавить в `main.js` по запросу (меню, трей-иконка,
  счётчик непрочитанных на иконке задачи).
